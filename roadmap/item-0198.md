Raised by the operator on 2026-11-18 at 39cd1d1, while settling the nine
rule (6) deferrals of item-0004. Rule (6) of ADR-049 removed one half of the
optional-versus-required confusion and left the other: an optional field
still accepts the empty list and the empty struct, so "nothing" has two
forms, and the value of a pattern constraint was not reached at all. The
operator ratified the generalization below on 2026-11-18.

## The rule, as ratified

- A field is a named member of a struct, whether declared or matched by a
  pattern. A map key is a field. A list element is not a field.
- No field holds "", null, [] or {}. A required field holds a non-empty
  form; an optional field is absent or holds that form. There is no third
  state.
- Every admissible choice has exactly one form, the form is documented, and
  the validator rejects every other one.

Forms, one per choice:

| Kind                          | Required                         | Optional                 |
|-------------------------------|----------------------------------|--------------------------|
| string                        | non-empty constraint             | same, field optional     |
| list                          | [T, ...T]                        | same, field optional     |
| pattern map                   | {[K]: V} and struct.MinFields(1) | same, field optional     |
| struct of optional fields only| not admissible                   | optional, MinFields(1)   |

Solution space, level 0 (the field f itself):

| Value of f    | Required | Optional |
|---------------|----------|----------|
| absent        | invalid  | valid    |
| ""            | invalid  | invalid  |
| null          | invalid  | invalid  |
| []            | invalid  | invalid  |
| {}            | invalid  | invalid  |
| "x"           | valid    | valid    |
| [e, ...]      | level 1, list column      | same |
| {k: v, ...}   | level 1, map or struct    | same |

Solution space, level 1 (the content of a non-empty f):

| Content                | List [e]          | Map {k: e} | Struct {a: e} |
|------------------------|-------------------|------------|---------------|
| "x"                    | valid             | valid      | valid         |
| ""                     | valid             | invalid    | invalid       |
| null                   | not reached (1)   | invalid    | invalid       |
| []                     | valid, degenerate | invalid    | invalid       |
| {}                     | valid, degenerate | invalid    | invalid       |
| ["x"] or [""]          | valid             | valid      | valid         |
| {k: "x"}               | valid             | valid      | valid         |
| absent, optional a     | --                | --         | valid         |
| absent, required a     | --                | --         | invalid       |

(1) The rule does not reach a list element; no type in the contract admits
null, so the element is rejected by its type.

Below level 1 the same holds recursively: every field follows level 0, and
every list element is free within its type. env: {FOO: ""} is therefore
invalid; a variable that must be empty is not declared.

## Mechanization and the Go side

The lint checks the rule by evaluation rather than by syntax: each field of
each definition is unified with the four empty values, and a result that is
not bottom is a finding. This observes the invariant directly and needs no
case analysis by depth; the syntactic required-collection check it replaces
cannot tell whether a regular expression admits the empty string. An
optional scalar whose Go zero value is admissible (false, 0) is nillable in
Go, so absence and the zero value stay two values.

How struct.MinFields behaves in validation, in the exported JSON Schema and
in gengotypes is measured before the instruction is authored; the stdlib
import it needs is also new to the tier rule of the lint.

## Entry parsers

The rule applies to input outside the contract as well, through the one
owning parser rule (1) of ADR-049 gives each value from the environment:
a set but empty value is malformed and is rejected with the name of its
source; a value that must be absent is unset. SOURCE_DATE_EPOCH unset is the
epoch, set but empty is an error; this supersedes "unset or empty" in the
ADR-015 amendment of 2026-11-17. At 39cd1d1 the environment is read for
SOURCE_DATE_EPOCH, CONTAINER_HOST, XDG_RUNTIME_DIR, CONTAINER_TLS_CA,
CONTAINER_TLS_CERT, CONTAINER_TLS_KEY, STRIKE_AUDIT, SSH_AUTH_SOCK and the
env:// secret sources of the lane and of the registry-token flag; a file://
secret source with an empty file is the same case.

## Amendment 2026-11-20 at 5490287: decisions after the two spikes

Two delegate-measure spikes ran at 5490287: the candidate forms with a
prototype of the evaluation lint, and the Go type redirects with the
required marker. The operator ratified the following from 2026-11-18 to
2026-11-20. It completes the rule in the notes above; where the two
differ, this amendment decides.

The rule is read on the written value. R1 judges what the author writes,
not the value evaluation produces once defaults are filled in: no author
can write the evaluated value. A field is a named member of a struct,
declared or matched by a pattern; a map key is a field, a list element is
not. env: {FOO: ""} is invalid, ["", ""] is a valid list.

Forms, one per choice:

- A string is non-empty by `!=""`, with no `strings` import.
- `struct.MinFields(1)` stands at the field that uses a type, never in the
  definition. In the definition it turns the generated Go type into `any`,
  drops `additionalProperties: false` from the exported schema and hides
  the definition's fields from the evaluation (measured). A struct whose
  fields are all optional carries it at every use, required or optional.
- A field that carries `struct.MinFields` names its Go type:
  `@go(Name,type=map[K]V)` for a map, `@go(Name,type=*T)` for an optional
  struct. `optional=nillable` together with `type=` drops the pointer and
  breaks the build (measured).
- No struct-valued field accepts {} (R7). `struct.MinFields` counts the
  evaluated fields, so a struct with a defaulted or constant field needs a
  field the instance must write. A union-typed field already rejects {}
  (measured for the deploy method and the engine).
- A field with a default is a regular field with an explicit default arm
  whose type follows the default (`forceRun: *false | bool`); an optional
  field never carries a default. In a lane such a field has three forms,
  three statements: omitted (the default applies), the default written
  (pinned against a later change of the default), another value. This is
  the form the ADR-056 amendment of 2026-09-06 chose.
- Every field typed with a discriminator vocabulary (deploy method,
  carriage, engine, credential) carries the required marker `!`, in the
  arm of a union and in the seed of a later union alike. Other constants
  stay without it. The marker leaves the Go types unchanged, adds `type`
  to the schema's `required`, and exports an arm made only of its
  discriminator as a `const` object (measured).
- An authority or URL never spells out the default port of its scheme,
  everywhere in a lane, as already for registries. `#Address.port` stays
  optional as the Go projection of that one grammar form.
- Two values the contract does not describe are exempt, by a closed list
  in the ADR-049 amendment: the open remainder of `#CycloneDXDocument` and
  the input of the attestation cross-validation vector.

Sites decided:

- `#DoT.port` becomes `port: *853 | primitive.#Port`; the default in Go
  goes.
- The lane's timeout moves to the lane as
  `timeout: *"10m" | primitive.#Duration`; `#LaneDefaults` and the
  fallback in Go go; `#Step.timeout` stays optional, absent meaning the
  lane's value.
- `recording` becomes optional, absent meaning no recording; `preState`
  and `postState` become optional; `captures` is a non-empty list. The
  comment "mandatory state recording" is corrected.
- `#DeployKubernetes` stays as a placeholder.
- `#EngineUnix` gets its marker here, with the other arms in
  contract/endpoint. This supersedes the decision of 2026-11-20 that left
  it to item-0004.

Mechanization:

- The lint checks R1 and R7 by evaluation: every field of every
  definition, pattern entries included, is unified with "", null, [] and
  {}, and a value the validator accepts is a finding. It replaces the
  syntactic required-collection check. A union is not entered; its arms
  must be named definitions and are checked as such. The tier check
  admits exactly the standard import `struct`.
- The JSON Schema export drops `struct.MinFields` (measured). A strike
  tool in the CUE codegen writes `minProperties` at every such field,
  beside a `$ref` where the field refers to a definition, and fails the
  generation on a site it cannot place. Basis: a dated amendment to
  ADR-017.
- Measured at 5490287, the prototype of the lint finds 138 sites plus the
  two exemptions. The 43 sites in contract/attest are deferrals owned by
  item-0004; the 95 others are owned by this item until their package
  migrates.

## Amendment 2026-11-21 at 6d83ff6: the lint, measured and decided

A delegate spike of the lint walk at 6d83ff6 measured 146 sites plus the
two exemptions. The prototype at 5490287 had not seen the entries of a
pattern whose key is constrained, nor the fields of a struct that is a
list element: contract/attest holds 51 sites, owned by item-0004, and
the other packages 95, owned by this item until their package migrates.

Decided by the operator on 2026-11-20 and 2026-11-21 for part 2:

- The walk enters every value that is not a bare reference, compositions
  included: a composition can make a nested struct accept {} that its
  definition rejects. A union is recognized before iteration, because
  iterating with patterns does not fail on one; it is not entered, and
  an arm that is not a named definition is a finding, also inside a
  conjunction.
- A site is the path from the definition, labels without ? and !; every
  entry beyond the declared fields and every list element is [_]. A
  deferral names the site, the empty values it accepts as the finding
  spells them, and its owner; a finding that differs is reported, and an
  entry without its finding is stale.
- Finding kinds: empty-value, union-arm, stale-deferral, and the two
  exemptions of ADR-049 as a closed list with stale-exemption. A value of
  no kind, a struct whose fields cannot be listed and a value of struct
  and list kind outside a union abort the run. The tier check admits the
  import struct. No finding message cites an ADR.
- The contract has no recursive definition. A dated amendment to ADR-049
  states the rule; the lint builds the graph of definitions from the
  written form, reports every definition that reaches itself, and while
  one does, does not walk the evaluated value.
- An optional field with a default arm and a definition with a default
  arm of its own are findings, checked on the written form; the
  amendment to ADR-049 states both.

Before part 4, which first brings struct.MinFields into the contract, a
measurement settles how the walk enters a value under struct.MinFields,
whose kind as a schema is bottom (measured), and whether Value.Default
reports a default for [T, ...T]. Part 4 then decides whether the check
of an optional default stays on the written form or moves to the
evaluated value.

## Amendment 2026-11-21 at 11b2999: a value of no kind that is a scalar

The first run of the part 2 lint over the contract stopped at
`#Entry.layer` in contract/trustlayers,
`#TrustLayer & layerOf[provenance]`: the schema leaves the provenance
open, so the index, and with it the value, has no kind. The prototype of
the spike had read every value of no kind as a scalar without recording
it, so the measurement did not show the site. By a search of the
contract source it is the one index expression there.

Decided by the operator on 2026-11-21:

- A conjunction one of whose conjuncts has a kind that admits neither a
  struct nor a list is a scalar and is not entered, whatever its own
  kind. Every other value of no kind still aborts the run; a struct
  under struct.MinFields is one, and the measurement before part 4
  stands.
- The walk visits the contract packages in sorted order, so a run that
  aborts names the same site every time.

Supersedes, in the amendment of 2026-11-21 at 6d83ff6 above: "A value of
no kind, a struct whose fields cannot be listed and a value of struct
and list kind outside a union abort the run." is read as: "A value of no
kind that no conjunct makes a scalar, a struct whose fields cannot be
listed and a value of struct and list kind outside a union abort the
run."
