Created by operator decision of 2026-11-06 (fork L4 of the item-0186
preparation).

Found by the item-0186 spike at 584b66a: cgr.dev serves the OCI referrers
API, and for cgr.dev/chainguard/static at its index digest it lists no
referrer, filtered or not, with the tag fallback refused. Chainguard
documents that it stores signatures and attestations under the cosign .sig
and .att tags rather than in the referrers graph, so the base-SBOM fetch,
which refuses the tag fallback, finds nothing and records no base SBOM,
without an error.

Chainguard announced a move to Sigstore v3 bundles: dual signing from
2026-11-16 to 2026-12-15, v3 only afterwards. Cosign v3 attaches bundles as
OCI referrers by default, so referrers are expected to appear for digests
published after the start date; the attachment point (index or per-platform
manifest) is not documented. The pack base reference a lane declares is the
index digest; the package SBOM is reported to hang off the per-platform
manifest.

Out of scope here: item-0006 (the live base-SBOM path against the harness)
and the in-run declaration of the hosts this fetch dials (item-0186).
