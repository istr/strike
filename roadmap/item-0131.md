Deferred out of the golden-generator rework, which could not carry it. The
lane fixture's header names a test function that rework deletes and carries an
instruction identifier the self-contained-comments rule forbids, so the edit is
warranted -- but lane.Parse hashes the file as read, comments included, and the
sealed predicate carries that digest. A comment edit alone therefore breaks the
UC2 verify path with a lane-digest mismatch, in a test that needs no harness at
all.

That makes this the ordinary case of the rule the golden README now states: a
change to this file is never editorial, and the forced regeneration lands as
its own commit rather than riding inside the change that provoked it. Here the
provocation and the regeneration are the same commit because the comment edit
is itself the only change.

Requires a running local sigstore harness, and a cold harness re-keys the trust
root, so budget all four generated files and gate on the set verifying together
rather than on any one file being byte-stable.
