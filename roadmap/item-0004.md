Engine-cluster LEAD: settles the shape so the hardening matching (engine-hardening item) is written once. Golden-affecting (resolver sealed). == cross-roadmap execution-order step 8. Migrated from the retired cue-spec-review.

Amended after a whole-strand read of mediator, peer and dial: ADR-028 commits
the attestation to record "destination IP and port" per connection, but
#ObservedPeer carries only resolved, the untyped candidate list the DoT lookup
returned, and the mediator drops every address after the first without noting
which one it dialed. The observed-shape decision this item owns is the right
place to settle that field, since it touches the same block of
contract/attest/attestation.cue.

Amended 2026-08-26 at dc83c97: the fingerprint clause is removed from the
acceptance. item-0075 landed that typing in ea6e2c5 -- engine server and client
cert, the ObservedSSH host key and the ObservedTLS server cert carry
primitive.#Digest, and every construction site goes through
primitive.DigestFromHex -- so no prefixed-versus-bare-hex split is left to
unify, and contract/primitive/scalars.cue holds no bare-sha256 primitive for
the clause's second arm to select. One bare-string fingerprint remains,
#ResolverRecord.serverCertFingerprint; item-0075 descoped it deliberately,
because #Sealed.resolver is required-but-emptyable and tightening it rejects
the valid empty-resolver deploy, and item-0098 owns it together with the
resolver-block optionality. This item consolidates shapes, not formats, and
inherits one settled prefixed form.
