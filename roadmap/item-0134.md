The end state of the harness arc, ratified as the target on 2026-08-20. The
README promises reproducible rootless lanes with no local toolchain. That
promise binds the product, and a lane user needs no compose -- but the harness
is the artifact with which a third party reproduces the attestation chain, and
today that needs more than podman. The sharper inconsistency is not the
toolchain but the pin: all nine default images in compose.yaml are digest
pinned, while the external compose provider that decides which containers exist
with which configuration is an unpinned distribution package. The optional
witness service is likewise built from a mutable git ref.

Shape: the topology is declared in CUE and a Go driver translates it into
libpod calls. Replacing a readable declarative file with several hundred lines
of imperative Go would trade one liability for a larger one; a driver that is a
translator rather than a topology keeps the declaration readable and satisfies
the CUE-first principle. The engine surface grows here -- network creation,
port publishing, network aliases, container creation -- and each addition is
separately ratified rather than arriving as a batch.

Owns the deferred full readiness coverage: the Makefile probed three of eight
default services, and the fourth, the timestamp authority, is covered for free
by the chain refresh. Extending gates to the remaining services is a behaviour
improvement rather than parity and belongs here rather than in the recovery
work.

Also owns a coupling worth solving here rather than separately: the harness
service addresses are hardcoded at seven sites across tests and the golden
generator, which binds the harness to a loopback host and breaks the moment the
engine holding it is not the local one. And the cosign conformance path, which
drives an external binary, can be brought under the no-subprocess invariant by
running cosign from a digest-pinned container through the engine API -- the same
machinery this item builds anyway -- without giving up the independent-verifier
property.
