Created 2026-11-08 from the item-0151 preparation, as a post-beta hardening item. Operator decision E of that date: a cgr.dev Go image sets GODEBUG=tarinsecurepath=0,zipinsecurepath=0 and is used only as a copy source, never directly, in bootstrap/Containerfile, bootstrap/lane.cue and the dev container. The Containerfiles do that with COPY --from; a lane has no COPY. Measured at 0aa7b9c: a step cannot run the image as a copy tool, because a step has no entrypoint field and the executor passes args as the command under the image's entrypoint, which is /usr/bin/go in the cgr.dev Go image. Decided: a pack source that names an image path, the lane counterpart of COPY --from, rather than an entrypoint field on the step, because the source image is then never executed. Until this item lands, bootstrap/lane.cue keeps the cgr.dev Go image as a step image; this item owns that departure from E. The GODEBUG setting reaches only the go process of those steps, not the binary they build. Also measured: pack applies mode only to a regular file whose name equals dest, so a directory output keeps the producer's modes and a declared mode is ignored without a diagnostic (internal/registry/seedtar.go); that silence is settled here, because the new source kind takes the same path.
