Register: the four remaining extractor fact classes from retrospective 6.3. Sequenced after items 0075-0083 so the gates land against a cleaned tree with small allowlists. linttypeflow stands up standalone and deliberately red at item-0073 (empty allowlist, TDD); the cleanup items drive it toward green under a no-red-regression rule; this item is the first point where every covered flow class passes together, so the standalone-to-aggregate promotion into make check lands here, mirroring the lint-cuecoverage lifecycle.

Amended 2026-08-22 from a gate run at the anchor where item-0086 was authored.
Eleven diagnoses stood open. Five are owned by cleanup items already -- the
hex-to-digest constructor and the resolveDigest split by item-0082, the
image-ref construction sites by item-0078, the output content prefix by
item-0079 -- and the remaining six land here, in two groups.

Four are analyzer defects, not code defects. AbsPath.String, Digest.String,
Host.String and RelPath.String are flagged by result-string-scalar, which is
exactly the case RB-04 and ADR-049 (3) exempt: fmt.Stringer is a foreign
interface and the value it produces is a message, not program state. Host.String
exists because item-0087 added it so callers stop writing a conversion
linttypeconv rejects in a call argument, so the two gates presently contradict
each other. The exemption cannot be an allowlist entry, because an entry carries
the roadmap item that will retire the site and nothing will ever retire a
Stringer; it belongs in the analyzer. This is load-bearing for the graduation
clause rather than cosmetic: the sanctioned repair for a detyped value is a
String projection in the owning package, so every roundtrip this gate drives out
can mint a fresh result-string-scalar finding, and the class cannot be green at
the same time as the others until the carve-out lands.

The other two diagnoses are one real finding in one function. Address.Authority
routes the host through an untyped local and the port through an int local
before retyping both into the wire form, which the gate reports three times. The
siting is correct under ADR-049 (2) -- the projection belongs to the package
that owns the concept -- so only the writing changes, and it changes by dropping
the locals rather than by moving anything. No other item owns it: item-0087 is
retired, and item-0098 and item-0101 are parked on different objects.

The execution profile rises from smallest/none to small/brief with these two:
the item now carries analyzer logic and a small production rewrite, not only
gate wiring.

Amended 2026-09-04 by item-0149. Three of this item's clauses are closed. The
Authority projection no longer routes host or port through untyped locals --
the port-to-decimal conversion is now owned by primitive.Port.String, mirroring
Host.String -- and BracketedHostPort was rewritten with it, since no item owned
it as a deferral. linttypeflow has graduated from the standalone lint-typeflow
target into the aggregate lint target and thereby into make check. The
result-string-scalar Stringer carve-out was already implemented in the analyzer
at that anchor: boundaryRecv marks a String method detyping its own receiver
and gateFindings drops it, so all five primitive String methods are exempt
without an allowlist entry. What remains here is the escalation of the four
judgment-adjacent classes and nothing else. Constructing the authority from
parts registers two retype-from-stringop facts, which is that class's
owning-package treatment to settle.
