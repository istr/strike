Register rows R-19 (consumer side), R-23, R-37, and R-41 (folded in from fork F). The containment-helper and path-method shapes follow the item-0072 ruling on R-37; everything else is unblocked.

Fork F is ratified (option 1): primitive.#AbsPath is the grammar of an absolute slash path and where it points is context, not type. The scalar doc drops its container-only prose (the #CABundle.path precedent was already location-neutral); the TLSConfig CAFile/CertFile/KeyFile env-derived host-path fields type as #AbsPath; lane.FilePath stays the operator-input wrapper it is. No sibling #HostPath is introduced. R-41 landed here rather than in a standalone item because #AbsPath is the path primitive this item already threads.

Amended 2026-08-22: takes over the transport.DialUnixSocket path parameter,
deferred out of item-0086. That item types the engine socket path but stops at
the transport signature -- DialUnixSocket still takes a plain string while its
siblings in the same file take concept types, and its second caller reads the
ssh-agent socket straight from the environment, so the retype needs exactly the
env-derived host-path domain ruling fork F already carries. Until it lands the
engine-address parser hands DialUnixSocket the sanctioned String projection,
which no gate reports; the deferral is therefore invisible to lint and is
recorded here instead of in an allowlist.
