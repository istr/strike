The capstone of the build-toolchain arc: the item that actually deletes the
root Makefile. It is the LAST build-toolchain item before the tag and is a hard
downstream of every other gate going go-native -- item-0035 (cue codegen/fmt),
item-0093 (Go-type linters), item-0094 (cuelint), item-0095 (shell gates) --
plus item-0063 resolved to option B, whose dogfood strike lane is the
orchestration that replaces the aggregate `make check`. Until that lane exists
there is nothing to delete the aggregate into. The residual thin wrappers
(build flags, golden-update, test, integration, vuln, lint-arch, lint-ci) move
to go:generate directives, the gate lane, or documented go commands. The docs
migration is in scope, not a follow-on: leaving `make X` in AGENTS.md and the
workflow docs after the file is gone is a broken instruction, not cosmetic.
Note item-0097 retires the second (sigstore-local) Makefile; both must land for
a tree with zero Makefiles.

## Amendment 2026-09-05 at c01be87: re-derived against ADR-055

The dependency on item-0063 is removed and the direction reversed as a
preference in _order.md, not as an edge. The paragraph above calls the
dogfood lane "the orchestration that replaces the aggregate make check";
ADR-055 D4 strikes that phrase from both items. The lane is the commit
gate; the working-tree gate is a documented sequence of go-native
commands run inside the dev container, and this item writes that
sequence into AGENTS.md. A lane step cannot call make -- make runs its
recipes through /bin/sh, which is a shell on the execution path -- so the
lane's steps are the very commands this item documents, and this item
comes first.

The rehome list closes for lint-arch here (ADR-055 M4): the architecture
linter becomes a tool directive in go.mod, verified against go.sum, and
the go run module@version form that has to write to the checksum
database at run time is retired.

"Dead by environment" needs one precision. ADR-055 says the root Makefile
is dead on the reference endpoint by environment; that holds for the
host. The dev container image at c2f602c installs make, so inside it the
file still runs. The deletion is therefore this item's decision, and the
reason is the one the arc always had: no Makefile remains in the tree.

The acceptance widens from six named files to every file carrying a
make-target reference. Measured at c01be87 outside roadmap/ and
docs/retrospectives/: 25 files. Beyond the six already named, these
include CONTRIBUTING.md, DEVELOPMENT.md, FIELDALIGNMENT.md, the
contract README and three CUE files that cite a target in a comment, two
Go test files, tools/gengolden, the harness recovery helper's cold-start
hint, the harness README and compose file (both on item-0133's surface),
ADR-017, ADR-050, ADR-052, ADR-055, ADR-INDEX and the Beta Definition of
Done. The last six are append-only: they receive dated amendments, not
in-place edits.

The note that item-0016 might add a make target and make this item an
amendment candidate is void: under D4 item-0016 adds a lintcue rule or a
gate entry in the documented sequence, and it lands before this item.
