Created by the roadmap revision behind ADR-055; the ADR names this item
in D3 and in its consequences.

The version at c2f602c is a measured first version: its Node.js runtime
comes from a distribution repository, is past upstream end of life since
2026-04-30 and below the agent package's declared floor, and the agent
arrives through a Dev Containers feature whose version floats on
rebuild. A feature is a shell installer over unpinned repositories, which
is why D3 forbids the mechanism rather than pinning it. The Containerfile
header says so; this item removes that header.

The pin gate rides here because the change it guards lands here, so the
gate is green at introduction (the item-0145 principle). It lives in
lintdoc, the existing home for tree-wide checks that need no Go type
information; no new tool. Ratification point: the package-manager rule.
At the anchor both this Containerfile (apt-get for nodejs and npm) and
bootstrap/Containerfile (apk for git) install from a distribution
repository; a rule that forbids it is red on both until each finds a
pinned source -- for git, a cgr.dev image that carries it is the obvious
candidate to measure.
