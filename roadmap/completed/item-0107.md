ADR-051 D9. Restructuring chosen over a map constraint (ratified cut-fork): it makes the D9 cardinality structural and absorbs the R-05 key-typing and wrap-unwrap churn item-0100 tracked, so item-0100 is retired moot alongside this item. The #ArtifactSource disjunction and its default-marker subtlety dissolve. ## Final summary

Landed as f872d435, leaner than the title. DeploySpec.artifacts is reduced to a single optional #StepImageRef -- a registry deploy references exactly one produced image (ADR-051 D6/D9) -- and the #ArtifactSource/#ArtifactRef disjunction with its Go union (artifact_source.go) is removed. The SBOM-region decomposition in the original goal did not land: during ratified analysis the reference model was reconceived so a deploy references a whole image product and SBOM over that image is item-0108, so there is no region map. The field is optional; the required-for-a-registry-deploy obligation binds with the push in a later item. Unchanged on purpose: the deployer resolved-reference map, resolveArtifactDigests, projectSubject, and attestation.cue, because a zero-or-one-entry map carries the one image now and the kubernetes array later. make check green.
