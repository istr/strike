An image output is addressed by step and has no output name (ADR-046), and an input reference requires an output name, so two images cannot be mounted into a step that compares them; strike compare compares two files and cannot be fed two step images. The compare therefore has to be a control-plane act. Depends on the topology decision because that decision fixes whether the in-lane double build is the proof shape; it is, so the second build runs with forceRun and the cache is bypassed, which makes the compare a literal check of the SLSA v1.2 Isolated clause that the output is identical whether or not the cache is used. Revival of the parked valid_force_run fixture (item-0147) would exercise the same semantics.

## Restated 2026-10-25 at 013959b: the compare is a gate of the registry deploy

The item first asked for a compare step kind that emits the agreed digest as
a file output the deploy names as a region. Read at 013959b, that shape does
not work as written. ADR-051 D9 defines the regions of a registry deploy as
regions of the pushed image, and the registry validator requires every region
to be packed into it, which a compare output cannot be without a cycle. A
compare step that nothing consumes is a non-deploy leaf, which ADR-039 D5
rejects. And a step failure stops only its own successors (ADR-039 D5), so
without an edge into the deploy the push can run before the compare fails.

Operator decisions of 2026-10-25. The compare is a gate of the registry
deploy itself: reproducedBy, a single optional step id on #DeployRegistry,
where the one image arm is defined (ADR-051 D9). There is no new step kind,
no digest file and no region. The gate compares the manifest digests on the
two image handles and nothing else: since item-0164 every image output is a
pack output, the layout tar is a deterministic function of the assembled
image, and its length is bound into the manifest by the content-size
annotation, so a layout-byte comparison adds nothing a published artifact
carries. The attest wire stays frozen: the gate is declared in the lane
whose digest the attestation seals (ADR-041), an attestation exists only if
the gate passed, and the compared digest is already the image arm's artifact
record. The golden is lane fixtures plus a hermetic deploy test; a
cross-validation vector is not added, because comparing two digests is no
boundary between implementations.

The reproducedBy step joins the never-cached set beside the deploy
artifacts: a cache-restored image handle carries no control-plane anchor,
and ADR-009 C1 needs the second build produced in the same run. The cache
key of a pack step covers less than its image is assembled from; that
defect is item-0124's and does not reach this gate, because both compared
steps are always produced. The stop is branch-local: the gate fails its own
deploy, and a deploy that declares no gate is not stopped by it. The second
build keeps forceRun on its build step as ADR-009 requires; writing that
lane is item-0150's.

## Final summary
