The two checks are the cross-control-plane and the strike-free halves of the
reproduction matrix. The commit gate's build step is already a plain go build
in a digest-pinned Go image orchestrated by the released strike as a sibling
(item-0063), so the cross-control-plane half costs one pack step and one
recorded digest, not a second pipeline. With one topology in the tree, the
engine diversity of this check comes from the two hosts -- the operator's
endpoint and the forge runner -- not from a nested engine; running both
halves on one machine proves less, and the release procedure says so. The
strike-free half replaces ADR-009's current advice that a distrusting
operator run the bootstrap locally, which still requires trusting strike.
The stage_1-versus-lane binary comparison is a bonus: the Containerfile
builds with the go.dev toolchain of the golang alpine image and the lane
with a Wolfi-built toolchain, so equality at matching versions is agreement
between two independently built compilers of the same version, the cheapest
form of toolchain diversity available; it stays informational until
item-0062 aligns flags and versions, and it is lost if item-0062 moves the
builder stage onto the same toolchain image the lane uses -- that trade is
named there.

## Amendment 2026-10-29 at 02f3c00: ADR-057 fixes the direction

ADR-057 D4 keeps ADR-009 C2's two hosts and two control planes and fixes
the direction: the endpoint reproduces the forge, and the approver signs
only after that reproduction. The cross-control-plane, cross-host check of
this item reads in that direction. While pre-beta builds run on the
endpoint (operator decision of 2026-10-29), both sides run on one host,
which this item already states proves less.
