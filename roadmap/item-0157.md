At 7b09365 lane.yaml references a step src it does not declare, and every anchor in the file is the fixture anchor with example.com endpoints. ADR-009 itself names the containerized fetch as the path that retires the one residual shell expansion of the Containerfile; the Containerfile keeps its own fetch because stage_0 must compile the tree, but stage_2 and everything after it stop depending on the baked copy. The git image is a lane image reference and therefore digest-pinned by schema; the Containerfile's apk-installed git is item-0151's ratification point, not this item's. Whether the fetched tree's output digest is stable across fetches is a measurement, not a reading: a checkout stamps working-tree mtimes with the checkout time.
