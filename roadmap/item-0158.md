An image output is addressed by step and has no output name (ADR-046), and an input reference requires an output name, so two images cannot be mounted into a step that compares them; strike compare compares two files and cannot be fed two step images. The compare therefore has to be a control-plane act, like pack, and a predecessor of the deploy, like every gate step under ADR-039 D5. Depends on the topology decision because that decision fixes whether the in-lane double build is the proof shape; if it is, the second build runs with forceRun so the cache is bypassed, which makes the compare a literal check of the SLSA v1.2 Isolated clause that the output is identical whether or not the cache is used. Revival of the parked valid_force_run fixture (item-0147) would exercise the same semantics.
