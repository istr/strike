Parked by ADR-057 D4 as a post-beta hardening candidate, not ratified. The
release tag is signed with the approver's device and verified by git and
the forge; checking it inside strike verify needs a CMS or SSH signature
parser and a git object reader in strike, or exec, which ADR-057 rejects for
the beta.
