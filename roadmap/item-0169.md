Carved out of item-0166 by operator decision of 2026-10-29, in the roadmap
revision behind ADR-057.

Delegate spikes ADR-057 lists that precede this item's instruction: the
sidecar, agent and PKCS#11 path on the reference endpoint with the
operator's reader; the signed tag with the device key. The same agent
signs the release tag (D4); git and the forge verify it, strike verify does
not, and item-0170 parks the in-verifier check.

The residual D9 names stays named: an extra signature obtained in the
authorized session, combined with a candidate's valid provenance signature
and push rights, yields a bundle set the verifier grades release. The
release procedure's log monitoring and session bound are the mitigations,
not a closure.

The two checks D8 defers to the authoring of the concrete instruction: an
equivalent hardware-bound identity outside the EU with Linux PKCS#11
support, so the approver identity is not bound to one jurisdiction; and
the data-protection questions of publishing a natural person's certificate
in an append-only public log, the real name being the default.
