Register rows R-15, R-16, R-21, R-24, R-25. The id-token-as-SecretString change is independent of the forks and can lead. R-20 (issuer/identity typing, fork C) moved out to item-0085, which lands the repaired #URL primitive, the endpoint.Address marshalers, and the #StringOrURI scalar as one atomic wire-neutral change; this item consumes the already-typed forms, including the cert-issuer comparison projecting via issuer.URL().

Fork D is ratified and its infrastructure has landed, so the layer-name maps
(R-24) are unblocked. The enum policy is: a top-level string-disjunction
definition generates a named Go type, and the genenums pass emits its values as
unexported typed constants beside the generated types; the vocabulary is never a
public call-site literal, so consumers reach it through a method owned by the
type's package; union discriminator tags stay boundary literals and are out of
scope. The exhaustive linter is wired and checks any switch over such a type.
The blueprint is the deploy strategy enum (commits c40ebe9, aa1a9a1). Applying
the policy to the layer names requires hoisting that vocabulary to a top-level
definition first, which is a confirmation-gated CUE change.

Absorbed from the item-0114 completion report: emitEnums returns early on a
package with zero string-disjunction defs but never removes a previously
written enum file. Deleting record.#Format left an orphaned
internal/record/record_enum.gen.go referencing a deleted type and broke the
build until removed by hand. The layer-name hoist this item performs exercises
the same emit path; the zero-defs branch gains the removal.
