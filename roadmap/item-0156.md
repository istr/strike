ADR-055 D7 measured M2 (host networking) and M3 (socket reachability) for
the dev container; the bootstrap reuses that mechanism with a different
image and no shell, so this spike is a re-measurement with three additions:
the port behaviour of two controllers on one loopback, engine-side
configuration injection into step containers, and the token path. It
replaces the nested-topology spike this item carried before the sibling
decision of 2026-09-14; no nested engine is measured anywhere any more.

The Containerfile header still documents COSIGN_PRIVATE_KEY and
COSIGN_PASSWORD, which ADR-043 retired, while the keyless chain takes an
ambient id token (ADR-040); how that token reaches a run started on the
reference endpoint is the open measurement item-0008 and item-0063 already
name, and this spike records the bootstrap variant of the same question
rather than deciding it.

Side finding to carry to item-0063: with one topology the engine
requirement is uniform, and a hosted forge runner may ship an engine below
the version gate strike enforces; the runner then needs an engine that
meets it, measured at authoring.
