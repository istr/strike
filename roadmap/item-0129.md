The package name came from Sigstore: the only genuinely bundle-scoped member is
the sigstore bundle media type. The DSSE pre-authentication encoding and the
in-toto payload type are not bundles, and the package doc plus ADR-044 already
describe the members correctly in prose as "wire-format primitives". The name
also collides three ways in the tree -- six files import two different bundle
namespaces at once, and one file mixes the sigstore protobuf Bundle, the
strike package, and its own ParsedBundle type.

The deduplication is the same defect class ADR-044 was written for: a rule both
roles must reproduce exactly, homed in a role package. The C2SP signed-note key
id and the PKIX Ed25519 parse each exist twice, once in the verifier production
path and once as a producer-side test helper. Drift between the copies does not
surface as a compile error; it surfaces as a golden fixture whose log id the
verifier never reconstructs. The key id rule in particular was established
empirically against the local harness and contradicts the obvious guess.

Naming caveat carried into the charter: "wire" already denotes the
operator-authored input format for the lane contract. The package doc must say
which wire surface it owns -- the signing and transparency-log constructions --
so the two readings stay distinguishable.

Out of scope and deferred deliberately: the RFC 8785 canonical JSON subset in
the deploy package has a single implementation and no consumer copy, so it is
not a deduplication candidate; the OCI referrer annotation keys are restated in
integration tests on purpose, as an independent assertion of the published wire
value.
