Found during the item-0156 spike of 2026-10-24: a lane fails at container
create with the engine's 404 when a step image is not in the store.
Introduced by ad2b28e (2026-04-01): the step start moved from the podman
CLI, whose default pull policy "missing" pulled implicitly, to the libpod
create endpoint, which does not pull. The engine pull method was only ever
wired to cache-tag lookups, and that wiring was removed by 096ad68
(2026-05-15); the integration tests pre-pull their images and masked the
gap. The libpod pull handler answers 200 before it pulls and reports a
failure only in its final stream object, which the pull method never reads.

Operator decisions of 2026-10-24. The control plane materializes the image
(option B), not an engine pull (option A): ADR-037 D1 (input reference
integrity), ADR-030 and ADR-040 D3 state that the controller recomputes the
content hash of an inbound image, and only a control-plane fetch makes that
true for external step images; under an engine pull the check is the
engine's, a Layer-E fact that no later step can lift to V. The step executes
by the declared digest (variant i), so a warm store needs no network and the
pin stays the execution anchor; executing by the resolved platform-manifest
digest (variant ii) was rejected because it needs an index fetch on every
run. Materialization is lazy, before create of a step that executes. The
policy is missing.

A delegate-measure spike precedes the implementation instruction, because
whether the engine resolves an image by its declared index digest after
loading it from an OCI layout whose index.json names that index is
engine-internal. It measures that, the naming the load needs for the
declared reference to resolve, a streamed load, an aborted load, and
concurrent loads of one image.

Not in scope: recording the control-plane-verified step image in the sealed
provenance, which is a trust-layer map change and a separate decision;
registries that require authentication. Points to confirm at authoring: the
platform the control plane selects from an index, and the transport and
resolver of the fetch (the pack base fetch is the existing precedent, and
ADR-030 makes the content, not the channel, the anchor).
