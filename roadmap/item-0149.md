Deliberate intermediate step, cut so the flow gate can graduate without first
landing the type-cleanliness arc. A measured survey at the anchor where this
item was written showed the three gating classes carrying seven findings in
four causes, while the four classes item-0084 escalates carry 133 facts, 83 of
them in production code. Graduating the gate is therefore separable from that
escalation, and separating it is what unblocks the build-toolchain arc
(item-0093, item-0094, item-0063) instead of queueing it behind eight
type-cleanliness items.

Nothing here is new scope. Each production change is a clause already ratified
inside another item, landed early for the one site that blocks the gate:

- the image-ref digest accessor is item-0078's ratified fork H, applied to the
  command-package resolution only; the other split reimplementations stay with
  item-0078
- the typed output content prefix is item-0079's amendment clause, which names
  the function and its consumers
- dropping the authority projection's locals is item-0084's amendment finding,
  which records that no other item owns it
- the standalone-to-aggregate graduation is item-0084's acceptance clause

Those four items are amended when this lands, so the clauses live in exactly
one place. What remains with item-0084 is the escalation of the four
judgment-adjacent classes and nothing else.

Ratified policy: production sites are typed, test-side round-trips whose
correct repair is a constructor signature change are deferred by an allowlist
entry carrying its owner. Exactly one such entry is expected, owned by
item-0082, for the digest hex constructor's own inverse test; retyping that
constructor reaches roughly a hundred call sites and needs a hex constructor
that does not put a conversion in a call argument, which is item-0082's work,
not this item's.

Recorded gate conflict: the authority projection holds the port in an int local
today, and a named assignment passes the conversion-ownership gate by design.
Removing the local moves that conversion into a call argument, where the
conversion gate rejects it. The ratified resolution is a String method on the
port primitive, mirroring the host one, so the defining package owns the
conversion. A side effect is that constructing the authority from parts then
registers a retype-from-stringop fact; that class does not gate here and its
owning-package treatment belongs to item-0084.

No depends_on on purpose: this item is cut precisely so that it blocks on
nothing.
