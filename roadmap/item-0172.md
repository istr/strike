Carved out of the ADR-058 preparation by operator decision of 2026-10-30 (Fork I): two producer fixes that item-0166 would otherwise carry, independent of the credential. Measured at 1344ed5: quay.io and Google Artifact Registry surface no derived artifactType for a manifest that sets only the config media type, and the client library's filter then drops strike's own descriptor from the referrers listing; the library's referrers tag fallback defaults to on, so a registry without the API would silently receive a tag, which the tree forbids. Runs after item-0081 and before item-0166 in the execution order.

Sharpened 2026-11-01 by operator decision. The explicit artifactType ships as the full OCI 1.1 artifact form cosign produces (manifest artifactType, OCI empty config, one layer), so strike's referrers converge on the ecosystem form; the dev.strike.statement annotation and its trust-layer vocabulary stay. The statement-bundle reader moves its authoritative check from the config media type to the manifest artifactType plus the layer media type and shares the bounded single-layer read with the base-SBOM reader. The tag fallback is refused on every referrer read, the base-SBOM read included; ADR-040 records this and the new form in a dated amendment. The library's in-memory registry derives artifactType from the config only, so the regtest package gains a registry that applies the OCI rule. No separate convergence item existed; this item carries it, and item-0006 and item-0007 are sharpened alongside.
